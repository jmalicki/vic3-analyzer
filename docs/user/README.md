## Game data you provide

Analysis needs definitions from **your** Victoria 3 install. Paradox game data is copyrighted — we never redistribute `common/`, localization, icons, or a derived defs blob. The **desktop/MCP** apps usually auto-detect Steam paths; the **web** app asks you to supply the `game` folder locally (nothing is uploaded). Prefer plaintext saves via [Save-game editing](https://vic3.paradoxwikis.com/Save-game_editing) when you can.
